关于 Agent to Figma

本插件让 AI Agent 通过 MCP 读取和修改 Figma，实现 Agent 辅助设计。基于 cursor-talk-to-figma-mcp （MIT）构建。

版本：1.1.0

使用步骤

  1. 启动本地中继（node node-relay/socket.mjs）
  2. 使用中继端口连接（默认 3055）
  3. 在 MCP 客户端里 join 中继日志中的频道
