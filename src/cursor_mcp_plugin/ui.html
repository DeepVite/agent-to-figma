使用步骤

  1. 启动本地中继（npm run relay 或 node node-relay/socket.mjs）
  2. 在「连接」页使用中继端口连接（默认 3055）
  3. 将上方提示词复制给 Agent，或在 MCP 客户端调用 join_channel 加入频道
  4. 可点右上角「−」折叠成窄条常驻，请勿关闭窗口

关于 Agent to Figma

本地 Figma MCP 桥插件，让 AI Agent 通过本机回环安全地读取、标注和编辑当前打开的 Figma 文档，无需 Bun，无任何第三方统计上报。
